Key Default Type Description
job-result-store.storage-path
 (none) String Defines where job results should be stored. This should be an underlying file-system that provides read-after-write consistency. By default, this is {high-availability.storageDir}/job-result-store/{high-availability.cluster-id}. Only applies if job-result-store.storage-type is FILE_SYSTEM.
job-result-store.storage-type
 FILE_SYSTEM

Enum

 Defines where the cluster job results are stored for persistence across leadership changes.

Possible values:
  • "FILE_SYSTEM": Entries are stored as files under the configured storage path.
  • "KUBERNETES": Entries are stored in a Kubernetes ConfigMap created by the cluster. Requires high-availability.type to be KUBERNETES.
